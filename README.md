# Com1 Hardware Appliance

A responsive, single-page presentation focused on the **Hardware Appliance** section of the [Com1 IP-based PA system page](https://com1pbx.com/com1-ippbx-solution-ip-based-pa-system). Hardware imagery is illustrative, not product photography.

## Run locally

```sh
npm install
npm run dev
```

To create a production build, run `npm run build`. Preview it with `npm run preview`. Run `npm test` to check the GitHub Pages asset paths.

## GitHub Pages

The site can also be published directly from the repository root. Its scripts, styles, fonts, and images use relative paths so they work under the `/Com1pbx/` project URL without a build step.
