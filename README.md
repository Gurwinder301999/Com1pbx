# Com1 Hardware Appliance

A responsive, single-page presentation focused on the **Hardware Appliance** section of the [Com1 IP-based PA system page](https://com1pbx.com/com1-ippbx-solution-ip-based-pa-system). Hardware imagery is illustrative, not product photography.

## Run locally

```sh
npm install
npm run dev
```

To create a production build, run `npm run build`. Preview it with `npm run preview`.
